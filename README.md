# SQL & Database Projects

A collection of SQL and relational database projects completed while learning
SQL, PostgreSQL, Bash scripting, and relational database concepts.

These projects were developed as part of the **freeCodeCamp Relational Database
curriculum** and helped me practice database design, SQL queries, relationships,
constraints, joins, and data manipulation.

## 📂 Projects

### 1. 🌌 Celestial Bodies Database
A PostgreSQL database containing information about celestial bodies.

**Concepts practiced:**
- Database creation
- Tables and relationships
- Primary and foreign keys
- SQL queries
- Data types and constraints

### 2. 🎯 Number Guessing Game
A Bash-based number guessing game connected to a PostgreSQL database.

**Concepts practiced:**
- Bash scripting
- User input
- Conditional statements
- PostgreSQL
- SQL queries
- Storing and retrieving player information

### 3. 🔬 Periodic Table Database
A relational database containing information about chemical elements.

**Concepts practiced:**
- Relational database design
- SQL queries
- Table relationships
- Primary and foreign keys
- Data retrieval and filtering

### 4. 💇 Salon Appointment Scheduler
A command-line appointment scheduling application using Bash and PostgreSQL.

**Concepts practiced:**
- Bash scripting
- PostgreSQL
- CRUD operations
- Foreign keys
- User input handling
- Database relationships

### 5. ⚽ World Cup Database
A PostgreSQL database containing information about World Cup teams and games.

**Concepts practiced:**
- PostgreSQL
- SQL queries
- Aggregation
- Filtering
- Joins
- Database relationships

## 🛠️ Technologies Used

- PostgreSQL
- SQL
- Bash
- Linux/Unix command line
- Git & GitHub

## 📚 What I Learned

Through these projects, I practiced:

- Creating and modifying relational databases
- Designing tables and relationships
- Primary and foreign keys
- SQL `SELECT`, `INSERT`, `UPDATE`, and `DELETE`
- `WHERE`, `GROUP BY`, `ORDER BY`, and aggregate functions
- SQL JOINs
- Database constraints
- Bash scripting
- Connecting scripts with PostgreSQL
- Using Git and GitHub for version control
